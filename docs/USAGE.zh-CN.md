# NeuroShelf 0.7.1 使用说明

## 打开与升级

从 [官方仓库 Releases](https://github.com/yuanxinz-666/NeuroShelf/releases) 下载 `NeuroShelf-0.7.1-Windows.exe`。这是 Windows x64 免安装版，将文件放在固定位置后双击运行。第一次打开会先解包，后续的文库保存在本机应用数据目录。

需要桌面入口时，可以右键 EXE，在 Windows 的“显示更多选项 → 发送到 → 桌面快捷方式”中创建。已有的开发目录快捷方式可以继续使用，不必重复导入文库。

已有用户更新前可先通过“备份与迁移”导出当前项目。退出旧版后打开新版，在同一 Windows 账号、相同应用数据配置下会继续读取现有文库。文库与 EXE 分开保存；将 EXE 复制到另一台电脑不会带走文库。

## 项目与文库

侧栏可以新建研究项目，填写研究问题、关键词和物种范围。不同项目分别保存论文、PDF、PI、候选论文、笔记和实验记录。内置 SC–SNr 示例项目提供 107 篇文献元数据与导读，PDF 需自行导入。

在“导入 PDF”中选择或拖入文件，支持批量导入。给已有文献补全文时，在文件下方选择对应论文；否则会作为新论文加入。PDF 会复制到本地文库，之后移动下载文件夹中的原文件不会影响阅读。

论文卡片底部“我的评价”可写一句自己的判断，会自动保存。顶部搜索可以匹配标题、作者、评价和笔记。“我的笔记”、收藏、模块和阅读状态帮助缩小范围。

## PDF、旁注与 AI

打开论文后进入 PDF 阅读器。选中一段可选择的文字，按空格即可询问 AI 这段原文的含义。输入框内的空格仍用于打字，生成中的回答不会因重复按键再次发送。扫描版 PDF 若没有文字层，需要先用其他工具 OCR。

高亮选区后可以添加旁注，点击旁注可回到对应页和位置。AI 与旁注侧栏可切换；拖动分隔条调整宽度，也可调整 AI 字号。笔记与阅读位置会自动保存。

AI 在“设置与 AI 连接”中配置：

- **使用现有会员**：程序查找本机已安装的 Codex，使用它的官方登录连接。登录后点击“检查连接”。无需把登录凭证或密钥复制给 NeuroShelf。
- **复制上下文**：将问题与原文复制到已有的 ChatGPT、Codex 或其他助手，需要手动粘贴，回答不会自动回到软件。
- **API**：自行配置 API Key 的可选连接，计费与会员连接分开；不希望使用 API 时保留其他方式。

本版界面固定 GPT-6 Astra，并提供 low、medium、high、xhigh、max、ultra 推理强度选项。连接时会检查账号可用的模型和档位；界面选项不代表账号一定有对应权限。切换档位影响下一次提问，已经生成中的回答保留原档位。

提问会发送选区、当前页文字和近期对话；图片或相关页由你主动附加。阅读、个人评价、笔记和实验记录本身无需 AI 连接。API Key 由 Windows 加密保存在本机，不包含在文库备份中。

## 候选论文和 PI

“项目总览”可以启动论文初筛、PI 调研和缺失 PDF 下载。调研区展示运行阶段、耗时、结果或失败原因，并可停止。候选论文进入“每周新论文”，由你决定是否正式入库；历史初筛与近期更新分别标记。

点击 PI 的姓名或“详细档案”查看研究介绍、论文图表、关键词、学术关系与资助项目。论文数据和深度档案可分别更新。来源与核对日期用于判断记录的时效性，名单和统计不保证完整。

近十年图表按最近十个日历年统计，当前年截至检索日。CNS 指 Cell、Nature、Science 本刊；子刊不计入本刊计数。中科院大类一区与 JCR Q1 可切换，并显示覆盖情况。

分区数据需自行导入 CSV，列名为：

```csv
system,year,issn,journal,category,quartile,scie,source
```

`system` 填 `cas` 或 `jcr`，`quartile` 填 1–4，`scie` 填 `true` 或 `false`，来源使用原始 HTTPS 链接。使用所选年份的分区版本统一回溯分类，不自动推定每篇论文发表当年的历史分区。无法匹配的记录显示未知。

每周一自动更新需要单独配置个人调度任务。项目中的开关用于提供“是否参与”的设置，程序本身没有后台定时服务。源代码中的 `scripts/project-inbox.cjs` 可供调度器读取项目和发布经过验证的候选批次，候选仍须用户审核。

## 实验进程与图片证据

在当前项目的“实验进程”点击“新建实验”，填写名称，并按需添加子步骤。思维导图按树形结构自动布局，可切换步骤列表、折叠、缩放、拖动画布或调整所属分支。

每一步可填写状态、计划或实验日期、目的、过程与结果、下一步及问题。状态分为待开始、进行中、已完成、受阻；完成比例按步骤数量统计。

证据图片支持选择文件、拖入或粘贴，格式为 PNG、JPEG、WebP。单张上限 20 MB、4000 万像素，每步最多 60 张。可写说明、预览和保存原图；图片原件复制到项目文库中。暂时不用的分支可以归档，之后恢复。

编辑内容自动保存。离开页面或关闭窗口前，程序会提交当前草稿；保存失败时会保留草稿并提示重试。Markdown 导出包含步骤文字与图片索引，携带图片原件请使用完整备份。

## 备份与数据位置

“备份与迁移 → 导出完整资料库”备份当前项目的论文、阅读资料、PI、实验记录、PDF 和证据图片。多项目请分别备份。恢复时选择备份文件夹中的 `library.json`，并保留整个文件夹结构；单独一个 JSON 无法恢复图片与 PDF。不同项目身份的备份不会直接混入。

“导出阅读笔记 Markdown”包含个人评价、高亮、旁注、笔记和 AI 对话。实验进程有独立的 Markdown 导出入口。

默认项目位于 `%APPDATA%\NeuroShelf\projects`。已有安装如配置了自定义目录，以“项目总览 → 打开项目文件夹”显示的位置为准。

```text
project.json              项目问题、关键词与设置
library/library.json      文献、笔记、PI 与实验步骤
library/pdfs/             PDF 原件
library/evidence/         实验证据图片
inbox/papers/             候选论文批次
inbox/people/             PI 与档案批次
reports/                  调研记录
downloads/                全文下载记录
resources/                补充资料
```

如需整套迁移到另一台 Windows 电脑，请在退出程序后复制完整项目根目录，并保留项目索引与文件夹身份。每个项目的文库导出适合独立备份；它不包含全局登录信息、调度任务或项目根目录设置。

## 下载校验与问题反馈

发布页同时提供 `SHA256SUMS.txt`，可在 PowerShell 中计算并对照：

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\NeuroShelf-0.7.1-Windows.exe'
```

遇到问题请在 [GitHub Issues](https://github.com/yuanxinz-666/NeuroShelf/issues) 说明版本、操作步骤和错误提示。截图与日志如包含个人笔记或研究数据，请先自行去除再公开。
