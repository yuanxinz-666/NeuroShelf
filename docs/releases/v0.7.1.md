NeuroShelf 0.7.1 将论文精读、PI 资料与实验进程放进同一个 Windows 研究项目工作台。

### 下载

下载下方的 **NeuroShelf-0.7.1-Windows.exe**，放到固定文件夹后双击打开。Windows x64 免安装单文件版，首次启动需要解包；普通使用无需安装 Node.js 或 Python。

`NeuroShelf-0.7.1-使用说明.md` 提供上手与备份步骤，`SHA256SUMS.txt` 用于核对下载文件。GitHub 自动生成的 Source code 压缩包供开发者使用。

### 主要功能

- 按项目管理文库、PDF、笔记、个人评价和候选论文。
- PDF 划词后按空格问 AI，高亮旁注、可调宽度与字号的阅读侧栏。
- 调用本机 Codex 连接，固定 GPT-6 并切换推理强度；实际可用性取决于账号权限与额度。
- PI 详细档案、近十年发表图表、关键词、CNS、可切换的中科院一区与 JCR Q1、学术关系及资助来源。
- 实验思维导图、步骤列表、状态进度、图片证据、归档恢复与 Markdown 导出。
- 按项目完整备份 PDF、阅读记录、实验记录与图片。

### 0.7.1 修复

修复异步文库快照可能覆盖较新 AI 对话的问题，并完善草稿保存与关闭窗口时的写入检查。

### 使用范围

内置 107 篇 SC–SNr 示例文献元数据与导读，不包含论文 PDF、个人笔记、实验数据或登录信息。已有用户在同一 Windows 账号和应用数据配置下继续读取现有文库，建议更新前导出备份。

每周候选收件箱包含在程序中，周一自动执行需要单独配置使用者自己的调度任务。PI 统计显示数据覆盖与来源；分区需要自行导入，本版不附带分区数据库。

本次提供 Windows 版本。完整说明见 [使用说明](https://github.com/yuanxinz-666/NeuroShelf/blob/main/docs/USAGE.zh-CN.md)。
