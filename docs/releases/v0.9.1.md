NeuroShelf 0.9.1 makes focus reading continuous and adds an AI sidebar you can open from the right edge.

### Download

Download **NeuroShelf-0.9.1-Windows.exe** below. This is a portable Windows x64 app. Bilingual user guides and SHA256SUMS.txt are included.

### Reading improvements

- **Read the entire PDF in focus mode.** Scroll naturally across pages with the mouse wheel. A small pager remains visible at the bottom with previous/next buttons and direct page entry. F11 and Esc still leave focus mode.
- **Open AI by moving to the right edge.** A visible AI tab also provides a click target. Hovering opens the sidebar without sending a question; unsent drafts remain after dismissal.
- The current page supplies AI text context and optional page images. Highlights and margin comments keep their own page anchors. Leaving and reopening focus mode retains the current reading page.
- Pages near the viewport are rendered on demand, keeping long documents usable without drawing every page at once.

### Updating

Close the previous version and open 0.9.1 under the same Windows account, then update your desktop shortcut. Existing project storage, papers, PDFs, PI follows, experiments, language preferences and AI configuration are retained. The public app includes sample records and excludes personal research and credentials.

### 中文说明

专注阅读现在可以用滚轮连续查看整篇 PDF，底部始终显示上一页、下一页和页码，也可直接输入页码跳转。鼠标移到右侧边缘即可打开 AI 助手，无需先选择文字；移入边缘不会自动发送问题，关闭后保留草稿。

滚动后 AI 引用文字、附图和阅读位置对应当前页面，高亮与旁注保留原来的页码。退出并重新进入专注模式会回到当前页。已有文库、PI 关注、实验资料及会员连接继续保留。

### Validation

95 unit tests cover persistence, undo, project isolation and continuous layout with mixed page sizes and long documents. Isolated Windows desktop checks exercise native mouse-wheel scrolling, edge hover, retained drafts, page-specific highlights and AI context, focus re-entry, keyboard and bottom page navigation, and existing reading workflows. AI responses are mocked. Both the directory build and portable EXE run the desktop checks; public source and packaged files are compared before publishing.
