NeuroShelf 0.8.2 adds editable progress summaries to experiment mind-map cards and adjustable widths for all workspace sidebars.

### Download

Download **NeuroShelf-0.8.2-Windows.exe** below, keep it in a permanent folder and double-click it. This is a portable Windows x64 app. English and Chinese guides and `SHA256SUMS.txt` are included; GitHub's Source code archives are for developers.

### What's new

- Every experiment step card has a **Current progress** text box below its title. Record what is complete or pending without opening the detailed editor.
- Progress summaries save automatically, appear in the step list, are searchable and are included in Markdown exports and full backups. Existing detailed records and evidence images remain intact.
- Project navigation, library information, experiment details and the reading AI/annotation sidebar all have draggable dividers. Each width is remembered independently.
- Reading mode keeps its own navigation width. Widen its icon strip to display navigation labels.
- Double-click a divider to reset it, use left/right arrow keys to adjust it, or Home/End to choose its minimum/maximum width. Layouts adapt to the available window space.
- Windows pointer releases outside a moving divider now end the resize gesture correctly.

### Updating

Exit the previous version, open 0.8.2 and update any shortcut pointing to an older executable. The project-location fixes from 0.8.1 are retained. Existing experiment records open without a migration step; the new progress field starts empty until you enter a summary.

The public package contains 107 sample paper records and guides. Personal PDFs, PI notes, experiment records, images and account settings are excluded.
