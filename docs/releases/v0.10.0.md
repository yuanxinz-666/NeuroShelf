NeuroShelf 0.10.0 connects your papers to the experiments they support.

### Download

Download **NeuroShelf-0.10.0-Windows.exe** below. The portable Windows x64 app, English and Chinese guides, and SHA256 checksums are included.

### Experiment references

- Select an experiment step, such as behaviour, and choose **Experiment references → Link papers** to add several papers from the current project.
- Assign multiple purposes: experimental ideas, protocol and methods, control design, data analysis, interpretation and background evidence. Write a separate purpose note for each paper and experiment.
- Use the same paper in several experiments. Open its PDF or guide and return to the selected step.
- Filter the library by experiment and purpose. Parent experiments include papers linked to their substeps. Search also matches experiment names and purpose notes; paper cards provide a second linking entry point.
- Autosave, Ctrl S, undo/redo, failed-save retry and normal-close saving cover purpose notes. Complete backups and experiment Markdown exports include references. Unlinking retains the original paper, PDF and reading notes; archiving retains the experiment's references.

### 中文说明

每个实验步骤新增“实验参考文献”，可从当前项目文库批量添加论文，按实验思路、操作方法、对照设计、数据分析、结果解释和背景依据分类，也能逐篇写下对实验的具体帮助。

同一篇论文可以服务多个实验，各自保存用途与备注。文库支持按实验和用途筛选；选择父实验时也包含子步骤的论文。点击论文卡片下的实验入口，也能建立关联。阅读后可以回到原实验步骤。

### Updating and validation

Close the previous version, then open 0.10.0 under the same Windows account. Existing project storage, PDFs, PI follows, experiment records and language preferences are retained. The public build contains example metadata and excludes personal research files and credentials.

101 unit tests cover data persistence, reference validation, concurrent edits, project isolation, backups, filtering and undo/redo. Isolated desktop checks cover batch linking, multiple purposes, independent experiment notes, native saving, failure retry, library filters, navigation and persistence after reopening. Existing focus reading and AI routing checks also pass; AI replies in these checks are mocked. Both Windows directory and portable builds are tested, and the public source build is compared with the packaged files.
