NeuroShelf 0.8.1 fixes project storage selection and persistence on Windows, where opening a different data folder could make saved PI profiles, follows and detailed dossiers appear to be missing.

### Download

Download **NeuroShelf-0.8.1-Windows.exe** below, keep it in a permanent folder and double-click it. This is a portable Windows x64 app; normal use does not require Node.js or Python.

The release includes English and Chinese guides (`NeuroShelf-0.8.1-Guide-en.md` and `NeuroShelf-0.8.1-Guide-zh-CN.md`) and `SHA256SUMS.txt` for file verification. GitHub's Source code archives are for developers.

### Fixed

- The running desktop app now records its verified project storage location in its own Windows application data context, so the selection survives restarts.
- **Backup & transfer** shows the current project storage folder and provides an **Open existing project storage folder** action. Select the folder containing `index.json` to reopen an existing workspace with its PI profiles, follows, dossiers, paper records and experiment progress.
- Existing folders are checked before the app changes its saved location. Empty or incomplete folders do not replace the current workspace.
- If a remembered project folder becomes unavailable, the app reports the problem instead of silently creating a fresh sample workspace.
- Pending changes are saved before switching storage folders. Both folders remain intact; this action opens the selected workspace and does not merge separate copies automatically.

English and Simplified Chinese remain available, and the selected language is retained. The public package contains 107 sample paper records and guides, without personal PDFs, notes, experiment data or account settings.

### Updating

Exit the previous version, open 0.8.1 and update any shortcut pointing to an older executable. If your records appear incomplete, check the current path in **Backup & transfer**, then open your original project storage folder. If you have edited two separate copies, back up both before combining their data.

### 中文说明

修复 Windows 下项目目录记忆不完整、打开初始示例文库后 PI 数量和关注记录看起来减少的问题。软件现在会自行保存已验证的项目目录，并在重启后继续使用。

在 **备份与迁移** 中可以查看当前目录，通过 **打开已有项目资料夹** 选择包含 `index.json` 的原项目目录。选择后会显示该目录中原有的教授、关注、详细档案、论文及实验记录。原目录和当前目录都会保留，不会自动合并两份资料；若两份都有新记录，请先分别备份。已记住的目录暂时无法访问时，软件会提示错误，避免再次悄悄打开初始示例文库。
