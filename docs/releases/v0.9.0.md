NeuroShelf 0.9.0 adds fullscreen focus reading and workspace keyboard shortcuts.

### Download

Download **NeuroShelf-0.9.0-Windows.exe** below, keep it in a permanent folder and double-click it. This is a portable Windows x64 app. English and Chinese guides and SHA256SUMS.txt are included.

### Focus reading

- Open a PDF and press **F11**. The paper fills a native fullscreen reader with a black surround; navigation and permanent sidebars are hidden. The paper keeps its original colors.
- Select text with the left mouse button to reveal color and comment tools beside it. Press **Space** or click **Explain selection** to open a resizable floating AI assistant using your existing connection.
- Move to the top edge for page/search/zoom controls. **Esc** dismisses floating tools, then leaves fullscreen.

### Keyboard shortcuts

**Ctrl S** saves pending records immediately. **Ctrl Z** undoes a user edit; **Ctrl Y / Ctrl Shift Z** redoes it. **Ctrl F** finds PDF text, **Ctrl K** focuses search, **Ctrl O** opens PDF import, arrow/Page Up/Page Down keys turn pages, and **F1** displays shortcut help.

Text fields retain native text undo/redo. Elsewhere, each project's history covers up to 100 edits in the current app session, including highlights, comments, paper records, PI follows/notes and experiment edits. Undo preserves independent AI replies and reading positions; failed or conflicting operations leave stored records intact. PDF imports, backup restoration and AI requests are outside this edit history.

### Updating

Exit the previous version, open 0.9.0 and point your shortcut to the new executable. The existing project-location, language, PI profile and experiment progress features are retained. Personal PDFs, notes, experiments, images and account settings are excluded from the public package.

### Validation

93 unit tests cover persistence, project isolation, undo/redo conflicts and write failures, annotations, experiments, PI data, and existing workflows. Desktop checks use synthetic PDFs and mock AI responses to exercise native fullscreen, mouse selection, contextual tools, typing, keyboard shortcuts and saving the last keystroke to disk. Directory and portable builds run the isolated desktop workflow. Published source is compared with the packaged app and release asset hashes are verified.
