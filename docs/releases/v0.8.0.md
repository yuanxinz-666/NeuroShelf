NeuroShelf 0.8.0 adds English and Simplified Chinese to the same Windows research workspace.

### Download

Download **NeuroShelf-0.8.0-Windows.exe** below, keep it in a permanent folder and double-click it. This is a portable Windows x64 app; normal use does not require Node.js or Python.

The release includes English and Chinese guides (`NeuroShelf-0.8.0-Guide-en.md` and `NeuroShelf-0.8.0-Guide-zh-CN.md`) and `SHA256SUMS.txt` for file verification. GitHub's Source code archives are for developers.

### What's new

- English is the default on first launch. Switch between English and Simplified Chinese in the top bar or Settings & AI.
- The selected language is retained across restarts, updates and project switches under the same Windows profile.
- Change language without leaving the current view or losing editing drafts.
- Choose the AI response language independently, or let it follow the interface.
- Translate a reading guide into English in the AI sidebar while preserving its original text.
- English navigation, reader and experiment controls, PI and inbox interfaces, status messages, native dialogs and export headings.
- An English repository homepage and user guide, with links to the Chinese versions.

Existing project libraries, PDFs, notes, PI records and experiment evidence remain in place. Original research content stays in its original language. The public package contains 107 sample paper records and guides, without personal PDFs, notes, experiment data or account settings.

### Updating

Exit the previous version, open 0.8.0 under the same Windows account and application data configuration, and update any shortcut pointing to an older executable. If you have not chosen a language before, the new interface starts in English. Select **简体中文** once to keep using Chinese.

82 unit tests pass. The Windows directory build and portable executable pass the isolated desktop workflow: language persistence, editing drafts, English PDF Space questions, independent AI response language, guide translation, PDF rendering, annotations, personal reviews, candidate review, PI profiles, experiment images and saving on close.
